# Variant Chat 1.0.3

Chat tabs, emojis, private messages and staff badges for Valheim.

- Works with BepInEx alone. Groups, Guilds and BetterChat are optional.
- Click names to DM, mention or mute players.
- Personal opacity starts at 50%. Notification sounds are optional.
- Server admins can change the shared size, title, colors and badges.
- Assign badges to individual Steam players in game. Everyone sees the result, and it saves on the server.
- Badges are cosmetic and do not grant admin powers.

Requires BepInExPack Valheim 5.4.2350 or later. Use the same build on the server and clients for shared settings and badges. Both players need the mod for DMs.

Settings and role lists: `BepInEx/config/Variant Chat/`.

Built for Valheim 1.0.15 on Windows with keyboard and mouse.
